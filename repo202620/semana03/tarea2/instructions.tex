\section*{Instrucciones}
Para cada uno de los siguientes problemas
\begin{enumerate}
	\item Formalice el problema describiendo sus entradas, salidas, precondición y postcondición.
		{\small \emph{*Veremos cómo hacer esto el jueves.*}}
	\item Dibuje el grafo de subproblemas de una instancia de tamaño moderado del problema.
	\item Defina la ecuación de recurrencia de la solución al problema.
	\item Diseñe un algoritmo de programación dinámica que resuelva el problema.
		Escríbalo en Java o Python. ¿Su solución es Bottom-Up o Top-Down? Justifique
		su respuesta.
\end{enumerate}
